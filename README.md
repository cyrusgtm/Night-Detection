## Project Overview

Low-light conditions significantly reduce the performance of object detection models because changes in illumination make it difficult to extract reliable visual features. DAI-Net addresses this using a Retinex-based approach that separates images into reflectance and illumination components, encouraging the detector to learn illumination-invariant features.

Our project provides a minimal, annotated, and executable implementation designed to explain and test whether Retinex-based features and mutual feature alignment between normal-light and low-light images improve object detection performance under changing illumination.

## Model Architecture and Mechanism

* **Input Data:** Normal/low-light synthetic image pairs of shape $B \times 3 \times H \times W$, generated by manually altering well-lit images to create corresponding dark versions.
* **Core Components:**
  * A frozen Retinex decomposition network that separates inputs into reflectance and illumination maps with matching spatial dimensions.
  * A detector feature extractor.
  * A reflectance decoder branch.
* **Training Objective:** Encourages the model to produce consistent features for the same scene under both normal and low-light conditions by adding a feature alignment loss ($\mathcal{L}_{\text{mfa}}$) that penalizes feature differences between the two lighting domains.

## Evaluation, Correctness Tests, and Ablation

* **Primary Metric:** Mean Average Precision (mAP).
* **Correctness Verification:**
  1. Verify that adding the reflectance components does not break baseline functionality by testing on standard well-lit images.
  2. Compare our proposed model against a standard object detector on the same set of well-lit images.
  3. Test and compare both models on low-light images.
* **Informative Negative Comparison:** Compare our zero-shot adaptation model against a standard object detector trained directly on raw synthetic low-light images. As shown in the paper, naive training on synthetic dark data degrades mAP (dropping from 15.2% to 11.6%), demonstrating that raw dark data alone is insufficient without explicit illumination-invariant adaptation.
* **Controlled Quantitative Ablation:** Systematically evaluate model performance with and without the mutual feature alignment loss ($\mathcal{L}_{\text{mfa}}$) to verify its contribution to low-light generalization.
